# Project instructions

- This is a separate beginner Python website for middle and high school students with no coding experience.
- Use simple English, visual explanations, distinct lessons, practice, and homework. Avoid childish language, idioms, and assumptions about students’ home languages or cultures.
- Keep the design calm and uncluttered, with light flat backgrounds, readable sans-serif text, and top navigation.
- Build and preview locally. Never use Sites or ImageGen. Do not write a README.
- Execute real Python in a local Pyodide worker. Preserve stop/time limits, friendly errors, and keyboard accessibility.
- Keep student work in this browser; do not send it to a server or add analytics.
- Run npm run build and npm test after substantive changes. npm test requires the local preview at port 5282.
